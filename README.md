线上：https://vincentzyuapps.github.io/koishi-plugin-wydashen-guangyi-query/

## 本地运行（默认端口 61127）

```bash
yarn install
yarn dev      # http://localhost:61127/koishi-plugin-wydashen-guangyi-query/
```

## 构建 / 预览

```bash
yarn build
yarn preview
```
